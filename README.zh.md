# JEV Control Your Roboarm

你用一句话说出要做的事。JEV 控制这只机械臂：它看着腕部相机目前能支持什么，选出一个允许的动作，机械臂去执行。动完之后相机再看一次，程序重新生成 prompt，JEV 再选下一步。这样重复，直到目标被检查过、JEV 来问你，或者轮数用完。

JEV 不发电机指令。每一轮它回答一组已经收好的问题。程序把这些回答收成一个动作和一组检查过的参数，再交给机械臂驱动执行。

## JEV 能控制机械臂做什么

| JEV 的选择 | 机械臂接着被允许做的事 |
| --- | --- |
| 寻找 | 只移动腕部相机，在当前画面、近处若干视角，或全部已配置的安全视角里找指定物体 |
| 观察 | 再用腕部相机看一次，并给出位置 |
| 抓取 | 抓住这一轮里已经看见并核对过的物体 |
| 放置 | 把手里的物体放到选定的目的地 |
| 核对 | 用腕部相机确认这次转移确实发生了 |
| 微调手 | 让手沿一个方向平移或转动一档，例如 3 毫米或 5 度 |
| 调整夹爪 | 保持、张开、闭合，或每指只改变一档开合 |
| 工具运动 | 保持不动，或走一段直线、圆弧、圆周，例如搅拌 |
| 结束 | 只有在成功动作之后又看过一次，才允许停 |
| 问你 | 目标或场景仍然不清楚时停下，把决定交还给你 |

选哪个动作、用哪一档幅度，是 JEV 的选择。这个选择允不允许、手臂怎么动，由程序和机械臂驱动负责。

## JEV 是怎么做到的

每一轮四步：感知，生成给 JEV 的 prompt，控制，再检查。

### 1. 感知

任务相机是腕部 RGB-D。深度把桌面上的物体分成簇，属于夹爪自己的像素被去掉，CLIP 给每个簇一个标签、颜色和抓取描述。这就是当前场景快照：看见了什么、在哪、标签有多确定。

JEV 的接口不记得上一次调用，所以程序自己保存场景记忆，并在每一轮重放。新的一次观察会并进旧记录，而不是把旧记录盖掉。记忆里有物体编号、每个标签被看到的次数、目前采用的标签、最近位姿、最多 20 次历史位姿、观察次数、现在是否可见，以及是否过期。一个物体若在后来的三次观察里都没再出现，会被标成过期，但不会被删掉。旁观相机、仿真真值，以及只用于验收的标记，会被拒绝，进不了这份记忆。

### 2. 生成 prompt

每一轮的 prompt 都重新做，不把原图塞进去，也不写成一段开放作文。

程序先打一个 `GIVEN THAT` 记录：

- 你的那句话，去掉首尾空白
- 控制约定：事实只来自机械臂自己的传感器和驱动；不允许仿真真值；JEV 选下一步动作和受限制的参数；校验、运动规划和执行留在普通代码里
- 当前驱动的能力，包括它实际能跑哪些动作
- JEV 可以选的动作清单，每一项带说明和合法输入；如果驱动声明了自己支持的子集，不支持的动作会在询问 JEV 之前拿掉
- 当前腕部快照
- 场景记忆：已知物体、置信度、观察次数、是否可见、是否过期、未知区域，以及最近的动作记录
- 只附最近 8 次动作结果，不附全部历史

产品窗口里看到的，以及运行记录里存的，就是这份记录。

然后同一份记录被拆成多道有固定答案的问题。每道题都有一句说明，答案列表由上面的事实生成：

- **下一步动作。** 答案是剩下的动作说明，再加上结束和问你。说明要求只使用用户目标、当前传感器事实和最近结果，不许编造物体或位姿。
- **是否可以继续** 和 **信息是否够。** 两个分数题。它们问的是：这一步能否在不编造坐标、不用真值的前提下尝试；腕部证据够不够做物理动作。
- **搜索目标。** 答案只来自驱动当前公布的视觉词表。选中一个名字，并不表示场景里一定有它。如果驱动没有公布词表，唯一的答案是问你，而不是发明一个类别。
- **目标和目的地。** 当前看见的每个物体各有一个答案；记得、但这一帧没看见的物体也各有一个。文字里写着标签、属性、位姿、观察次数和是否过期，并要求对过期或当前不可见的物体先再看一次再去碰。另外永远有两个答案：没看见，或者证据不足以确定是哪一个。
- **动作幅度。** 手、夹爪和工具的问题用有名字的档位（`fine`、`small` 等），文字里已经写明物理尺寸，例如 3 毫米或 5 度。JEV 不能自己填一个任意距离。

JEV 答完以后，普通代码把这些名字换回数值（`fine` 的平移变成 0.003 米）。如果 JEV 把目标或目的地标成没看见或不确定，对应引用会被清掉。

### 3. 控制

选中的动作必须仍在动作清单里。驱动接着执行：寻找和观察会移动腕部相机并再次读取；抓取、放置、微调、夹爪和工具运动走机械臂接口。下一轮开始时会再取一次腕部快照。动作结果同时写进 prompt 历史和场景记忆。

### 4. 检查

结束只是 JEV 的一个答案。程序只有在三件事都已经成立时才接受结束：JEV 至少做过两次决定，此前有动作成功，并且那次成功之后又拍过一次腕部快照。否则结束会被拒绝，拒绝本身记成一次动作结果，然后再次询问 JEV。如果 JEV 选择问你，循环停下来等你。如果新的 20 轮里都没有结束，运行会因为轮数用完而停下。

## 运行

需要 Python 3.11 或更新版本。仓库里带了一张桌面场景，用来试这只机械臂。

```powershell
python -m pip install -r requirements.txt
copy .env.example .env
```

在 `.env` 里填写你自己的 `AI_GATEWAY_API_KEY`，然后打开窗口，输入目标：

```powershell
python -m scripts.jev_robot.app --driver-factory scripts.jev_robot.drivers.isaac_rpc:create_driver --scene-id tabletop_household
```

也可以直接给一句话：

```powershell
python -m scripts.jev_robot.app --driver-factory scripts.jev_robot.drivers.isaac_rpc:create_driver --scene-id tabletop_household --goal "把糖盒放到红色方块上"
```

机械臂驱动默认连接 `127.0.0.1:47631`，可以用 `JEV_ISAAC_RPC_HOST` 和 `JEV_ISAAC_RPC_PORT` 修改。每次运行的 prompt、JEV 的回答、动作和腕部观察记在 `data/jev_robot/runs/`。
